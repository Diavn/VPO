## Scope
A holder of an existing valid synthetic verification token can download a one-page anonymous landscape PDF from /public/certificates/{token}/document.pdf. It is prominently labeled DEMO ONLY - NOT AN OFFICIAL CERTIFICATE; contains sample award, UTC issuance/check time, no recipient name, email, score, signatures or actual achievement claim. QR encodes the configured private gateway /verify-demo#token (localhost:8091 or exact configured Codespaces private HTTPS host), never a user-supplied origin. Browser removes fragment and prefills token; user must submit verification. The download link is rendered only for VALID_DEMO, cleared on page exit and subsequent checks. The server independently rechecks status on each request, returns 409 for held/revoked and 404 for unknown. Response no-store, attachment, fixed filename, no third-party requests. No schema change (37 tables/15 migrations). Existing rate limit retained.

## Limitations
This is a bearer-token verification slip, not a signed certificate or proof of identity, not automatic delivery to a student. QR contains the token; treat PDF as private synthetic data, never publicly distribute it. PDF is a snapshot and may become stale immediately after generation; it cannot be remotely revoked, always check live status. The token still appears in the API path; production log redaction, authorized delivery/recovery, individual staff identities, cryptographic signatures and formal award rules remain pending. Local QR only works where the private gateway is reachable; real Codespaces UAT and physical QR scan remain unverified. No production, no merge or public site modification.
