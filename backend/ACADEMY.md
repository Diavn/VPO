# VPO V4.7 — Academy & Learning Analytics
2026-11-25. Branch v4.7-academy-analytics derives from V4.6. Synthetic local source only; no merge to GitHub Pages main. No actual course purchase, exam selection, students, mentors, grades, fees or personal data.

## Pedagogy and measurement
One original illustrative foundation course, six lessons and three immutable essay submissions. The six lessons cover questions/concepts, theses/reasons, counterexamples, ethics, reasoned revision and transfer. Baseline (one prompt), revision (same question with prior mentor feedback and a required revision note), transfer (new fairness question) are separate tasks. Revision opens after baseline feedback; transfer opens after revision feedback. Lessons can be read anytime, so baseline is an initial submitted essay, not a controlled pretest. All prompts are synthetic and visible in source; no secure assessment or equivalent-form claim. No AI scoring, model calls, or automated sanctions. Mentor uses the V4.6 illustrative five criteria 0–4 each (DEMO-R1, not an approved rubric), with a passage/evidence explanation and actionable next step; feedback is immutable in this slice. Baseline/transfer conditions are self-declared independent or other, revision feedback-supported or other. These are not observed independent performances. No course fee or selection advantage.

Analytics: self-reported lesson completions / available lessons; submitted vs assessed tasks; baseline, revision, transfer totals /20; revision minus baseline only when both assessed; declared-independent transfer minus baseline only when both assessed and both declare independent. Missing assessment is null, not zero. Distinct prompts may have different difficulty, the same mentor may know the stage, and no causal, competence, mastery or validated growth inference is justified. No ranking, individual risk score, group aggregation or predictive analytics. No tracking outside course interactions. Future research requires comparable tasks, blind scoring, reliability, observed conditions, approved consent/ethics and separate research data.

## Student API
GET /me/academy — own enrolled courses.
GET /me/academy/{enrolment_id}/portfolio — course/lessons, unlocked tasks, own submissions/feedback, analytics.
POST /me/academy/{enrolment_id}/completion — {ordinal}, idempotent self-report.
POST /me/academy/{enrolment_id}/submissions — {stage,op_id,essay,condition,revision_note}, one immutable submission per stage; exact replay returns existing ID, conflict rejected. Max 40,000 UTF-8 essay bytes; revision note max 2,000. All writes use same-origin, student session, CSRF; runtime binds user ID from session. Direct DB role compromise can bypass user scope; full RLS/privilege threat model pending. No staff HTTP route. Stage/mentor operations serialize on enrolment row; database concurrency untested.
