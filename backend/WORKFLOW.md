## Staff CLI
From backend/, use the intended role's private DATABASE_URL and VPO_MODE=synthetic-staging. Input optional JSON via stdin, no real content. Examples of operation names:
- node workflow-cli.cjs queue < /dev/null — scope by role.
- node workflow-cli.cjs read_assigned ASSIGNMENT_UUID < /dev/null — own assignment only, returns pseudonymous case, submitted essay/topic and own scores. Does not expose profile, email, names or other examiner's marks; essay itself could identify author, production anonymisation review is required.
- printf '%s' '{"scores":[3,3,3,3,3],"reason":"Synthetic marking rationale"}' | node workflow-cli.cjs lock_mark ASSIGNMENT_UUID — one immutable mark per assignment.
- node workflow-cli.cjs moderation_detail CASE_UUID < /dev/null — moderator sees both marks and original essay.
- printf '%s' '{"award":"FIRST","reason":"Synthetic decision"}' | node workflow-cli.cjs propose CASE_UUID — exactly two locked marks from two distinct examiners required; award is a manual demo label, NOT automatically determined by score.
- If total scores differ by 4 or more, proposal requires adjudicated_scores (five 0–4 integers). It preserves original marks plus adjudicated scores and reason. Otherwise final score = mean of the two totals.
- node workflow-cli.cjs approve CASE_UUID < /dev/null — approver only; node workflow-cli.cjs publish CASE_UUID < /dev/null — publisher only. Publication means private synthetic result visible to owner, no public national award list.
- node workflow-cli.cjs reconcile ORDER_UUID < /dev/null — finance only, requires previously reported transfer and exact matching statement reference, amount and order. No manual PAID override, no QR or bank details.
- printf '%s' '{"decision":"REVIEW_REQUIRED","reason":"Synthetic review reason"}' | node workflow-cli.cjs appeal_decide CASE_UUID — independent appeal reviewer. DISMISSED or REVIEW_REQUIRED only. No silent score edit; new version/regrading process not yet implemented.
- node workflow-cli.cjs cert_issue CASE_UUID < /dev/null — cert officer only, published award and no OPEN or REVIEW_REQUIRED appeal, one certificate per result. Returns 64-hex token once and verification_path. Store securely for controlled delivery; no PDF/QR image or student token-delivery service yet. Path is payload for future QR, not a generated QR. Token hash at rest; access logs must redact token paths.
- printf '%s' '{"reason":"Synthetic revocation reason"}' | node workflow-cli.cjs cert_revoke_request CERTIFICATE_UUID — cert officer only. node workflow-cli.cjs cert_revoke_approve CERTIFICATE_UUID < /dev/null — cert approver, independent identity. Request puts verification on hold; approval revokes. Audit stores actor/action/object/time, not raw token or essay.

## Rubric DEMO-R1 (not an official IPO/VPO scale)
Five dimensions in fixed order: relevance, philosophical understanding, argumentation, coherence, originality/independence. 0 absent, 1 limited, 2 developing, 3 sound, 4 strong. Equal weights /20. Actual descriptors, weights, thresholds, discrepancy rules, calibration, COI, fairness, accommodation, prize quotas and team selection require academic approval. No auto-ranking/team selection. Threshold 4/20 is a provisional test setting, not validated reliability criterion. Independent examiners cannot see each other's marks through the CLI. Moderator, approver and publisher are different roles; no result amendments. An appeal review-required places verification on hold, not a changed grade.
