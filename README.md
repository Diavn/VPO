# VPO Digital Platform 4.0 — public preview

Draft, not official. Source: V4.0 Master Implementation & Governance package, brand assets V3.1, public IPO website and Tiền Phong article of 2 February 2026. The current vpovietnam.org site could not be retrieved for direct migration; no claim of full migration. Committee, partners, fees, contact details, individual awards, 2027 rules and photographs require BTC verification before publication.

## Preview
Open index.html in a browser or serve this directory with a local static HTTP server. No dependencies, analytics, server, form submissions, payments, or persistent browser storage. Language toggle, historical year filter and practice-only text editor (word count, local countdown, TXT export) are implemented. Practice timer is not server-authoritative and does not enforce exam rules. 

## GitHub
This preview now lives in Diavn/VPO, a dedicated public repository. It does not change vpovietnam.org. Enable GitHub Pages from Settings > Pages > Deploy from a branch > main > / (root) after review. BTC must approve ownership and publication. GitHub Pages can serve public content only; configure Pages explicitly after review, never place private data, credentials, payment configuration, unreleased exam topics or backend secrets in the repository.

## Before release
Confirm rights and accuracy of all content, run browser and accessibility tests, reconcile V4.0 requirements, approve logo and public data, and configure hosting security headers (including frame-ancestors, HSTS where appropriate). The meta CSP is only a limited client-side safeguard, not a security audit. Build authenticated backend, object-level authorization, database, private uploads, real server timer, financial reconciliation and anonymous grading separately. Complete G0–G4 and independent authorized security testing before official launch. All private modules remain disabled.
